# MyCalendar

A mobile-first personal planner with two primary screens: **Tasks** and **Calendar**.

## Features

- Add, complete, and delete tasks.
- Assign tasks to dates and see task markers on the calendar.
- Track completed tasks with the Little Wins count.
- Navigate dates and months.
- Save tasks in browser local storage.
- Use the account menu for Dashboard, Statistics, More, and Settings.
- Responsive layout with a sliding navigation drawer and animated add-task sheet.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Tasks are stored locally in the browser and are not synced between devices.
